Flexbox Froggy

Nível 11

A solução utilizada foi:

#pond {
    display: flex;
    flex-direction: column;
    justify-content: flex-end;
}

  • display: flex: ativa o Flexbox.
  • flex-direction: column: coloca os elementos em uma coluna, organizando-os verticalmente.
  • justify-content: flex-end: coloca os elementos no final do eixo principal. Como a direção é vertical, eles ficam na parte de baixo.

Nível 12

A solução utilizada foi:

#pond {
    display: flex;
    flex-direction: column-reverse;
    justify-content: space-between;
}

  • display: flex: ativa o Flexbox.
  • flex-direction: column-reverse: coloca os elementos verticalmente, mas invertendo a ordem.
  • justify-content: space-between: distribui os elementos deixando espaço entre eles.
