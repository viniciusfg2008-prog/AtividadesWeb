Grid Garden: explicação das soluções

Nível 3

#water {
  grid-column-start: 1;
  grid-column-end: 4;
}

Essas propriedades contam linhas do grid, e não colunas. Para cobrir as colunas 1, 2 e 3, a água começa na linha 1 e termina na linha 4, que é a borda direita da terceira coluna.

Nível 4

#water {
  grid-column-start: 5;
  grid-column-end: 2;
}

Quando o valor inicial é maior que o final, o navegador inverte os dois. Assim, a água ocupa o espaço entre as linhas 2 e 5, ou seja, as colunas 2, 3 e 4.
