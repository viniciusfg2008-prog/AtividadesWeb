O que é HTTP?

HTTP é um protocolo para buscar recursos, como documentos HTML. É a base de qualquer troca de dados na Web e é um protocolo cliente-servidor

Utilização na Web

  • Navegação em Sites: Quando você digita um endereço no navegador, ele age como cliente e pede a página ao servidor do site.
  • Carregamento de Recursos: O navegador monta a página inteira juntando vários pedidos HTTP para textos, imagens, vídeos e códigos.
  • Uso de Métodos (Verbos): Usa comandos como GET (para buscar dados) e POST (para enviar dados, como preencher um formulário).
  • Versão Segura (HTTPS): Adiciona uma camada de segurança e criptografia para proteger os dados trocados na rede.

Estrutura

  • Método (Verbo): A ação desejada (ex: GET, POST).
  • Caminho (URL/Path): O endereço do recurso no servidor.
  • Versão: O protocolo utilizado (ex: HTTP/1.1).
  • Headers (Cabeçalhos): Informações extras, como o tipo de navegador ou formato aceito.
  • Body (Corpo): Dados enviados ao servidor, usado em métodos como POST ou PUT.

Exemplos

GET

GET /api/v2/pokemon/pikachu HTTP/1.1
Host: pokeapi.co
Accept: application/json

POST

POST /usuarios HTTP/1.1
Host: meusite.com
Content-Type: application/json
Content-Length: 38
{"nome": "Ana", "email": "ana@email.com"}

PUT

PUT /usuarios/15 HTTP/1.1
Host: meusite.com
Content-Type: application/json
{"nome": "Ana Maria", "email": "ana.novo@email.com"}

DELETE

DELETE /usuarios/15 HTTP/1.1
Host: meusite.com
